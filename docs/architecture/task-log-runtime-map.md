# Task Log Runtime Map

Date: 2026-06-30

This document maps the current task-log runtime path. It is documentation only
and does not change UI, behavior, routing, server routes, styles, or data.

## Scope

Current runtime files and routes:

- Runtime binder: `src/client/features/workspace/task-log/task-log-runtime.js`
- Runtime mount call: `src/client/features/workspace/runtime/app-runtime-host.js`
- Static template: `index.html`
- Style entry: `styles.css` -> `styles/task-log.css`
- Server list route: `GET /api/ai/jobs`
- Server detail route: `GET /api/ai/jobs/:jobId`

Out of scope:

- No code changes
- No template extraction
- No CSS changes
- No server route changes
- No database or schema changes
- No handling of the existing `styles/task-log.css` worktree change

## Mount Path

Current client boot still follows:

```text
app.js
-> src/client/main.js
-> src/client/core/app-init.js
-> mountWorkspaceApp()
-> initializeAppRuntime(runtime)
-> bindTaskLogRuntime(runtime)
```

`initializeAppRuntime(runtime)` imports and calls `bindTaskLogRuntime(runtime)`.
The task-log binder collects DOM from `runtime.documentRoot` or
`globalThis.document`.

## Binding Preconditions

`bindTaskLogRuntime()` requires:

- `#taskLogPage` exists before binding.
- `#taskLogPage.dataset.taskLogBound !== "true"`.
- Task-log ids are available in the document:
  - `#profileView`
  - `#taskLogPage`
  - `#taskLogRefresh`
  - `#taskLogSearch`
  - `#taskLogDateFrom`
  - `#taskLogDateTo`
  - `#taskLogType`
  - `#taskLogStatus`
  - `#taskLogRows`
  - `#taskLogRange`
  - `#taskLogPrev`
  - `#taskLogNext`
  - `#taskLogLimit`
  - `#taskLogModal`
  - `#taskLogDetailBody`

The one-time binding guard is `#taskLogPage.dataset.taskLogBound`.

## Visibility And Refresh Flow

Visibility is derived from workspace routing:

```text
document.body.dataset.view === "space"
or
#profileView.classList.contains("active")
```

When visible:

- The runtime loads jobs if `state.loaded` is false.
- The runtime starts an 8-second auto-refresh timer.
- The timer skips refresh while `state.loading` is true.

When hidden:

- The auto-refresh timer is cleared.

The runtime watches `body[data-view]` with a `MutationObserver`. A template split
must preserve the route value `space` and keep `#profileView.active` behavior
compatible with workspace routing.

## User Events

Direct control bindings:

- `#taskLogRefresh` click: load jobs immediately.
- `#taskLogSearch` input: debounce filter refresh.
- `#taskLogDateFrom` change: debounce filter refresh.
- `#taskLogDateTo` change: debounce filter refresh.
- `#taskLogType` change: debounce filter refresh.
- `#taskLogStatus` change: debounce filter refresh.
- `#taskLogLimit` change: reset offset and load jobs.
- `#taskLogPrev` click: move offset backward and load jobs.
- `#taskLogNext` click: move offset forward and load jobs.

Delegated row actions from `#taskLogRows`:

- `[data-task-log-copy]`: copy task id.
- `[data-task-log-detail]`: open detail modal.
- `[data-task-log-output]`: open output preview modal.

Delegated modal actions from `#taskLogModal`:

- `[data-task-log-close]`: close modal.
- `[data-task-log-copy]`: copy text from detail/output content.

Global event:

- `Escape` closes `#taskLogModal` only when the modal exists and is not hidden.

## API Data Flow

List request:

```text
GET /api/ai/jobs?limit=<n>&offset=<n>&q=<text>&type=<type>&status=<status>&dateFrom=<yyyy-mm-dd>&dateTo=<yyyy-mm-dd>
```

Frontend list handling:

- `state.jobs` comes from `data.jobs`.
- `state.total` comes from `data.total`.
- `state.limit` comes from `data.limit` or the current selected limit.
- `state.offset` comes from `data.offset`.
- `renderRows()` updates `#taskLogRows`, `#taskLogRange`, `#taskLogPrev`, and
  `#taskLogNext`.

Detail/output request:

```text
GET /api/ai/jobs/:jobId
```

Server detail response includes:

- `job`
- `jobId`
- `remoteTaskId`
- `status`
- `progress`
- `createdAt`
- `updatedAt`
- `completedAt`
- `durationMs`
- `outputCount`
- `outputs`
- `imageUrls`
- `videoUrls`
- `imageUrl`
- `videoUrl`
- `failureCode`
- `failureMessage`
- `requestData`
- `responseData`
- `billing`

The server route is user-scoped through `req.auth.user.id`.

## Output Preview Classification

`collectOutputItems()` classifies outputs as:

- `model3d` when `output.type === "model3d"` or the MIME type contains `gltf`.
- `video` when `output.type === "video"` or the MIME type starts with
  `video/`.
- `image` for remaining URL outputs and `imageUrls`.

It deduplicates output URLs before rendering.

## Error And Loading States

List loading:

- Adds `.loading` to `#taskLogRefresh`.
- Removes `.loading` in `finally`.
- Writes a table error row on failure.

Detail/output loading:

- Opens `#taskLogModal` by setting `hidden = false`.
- Writes `.task-log-detail-loading` while fetching.
- Writes `.task-log-detail-error` on failure.

The modal close path sets `#taskLogModal.hidden = true`.

## Current Risks

- `styles/task-log.css` has an unrelated uncommitted worktree change and must
  not be included accidentally.
- The runtime directly queries ids from the document; a future template split
  must mount DOM before `bindTaskLogRuntime()` runs.
- `body[data-view="space"]` and `#profileView.active` are part of the runtime
  contract.
- `#taskLogRows` and `#taskLogModal` are event delegation roots.
- Generated selectors are both style targets and event targets.
- Console encoding can display Chinese text as mojibake in PowerShell; use
  `rg` or byte-aware checks before claiming source text is corrupted.

## Future Governance Rules

Before any behavior-equivalent task-log extraction:

- Re-run selector searches for task-log ids, classes, and data attributes.
- Preserve route value `space`.
- Preserve `#taskLogPage.dataset.taskLogBound`.
- Preserve generated row/detail/output selectors.
- Preserve API calls to `/api/ai/jobs` and `/api/ai/jobs/:jobId`.
- Preserve native `hidden` behavior on `#taskLogModal`.
- Do not combine template extraction with CSS migration.
- Do not include `styles/task-log.css` unless that is the explicit task.

## Smoke Verification Path

Minimum manual smoke after any future task-log runtime or template movement:

1. Navigate to the space/task-log view.
2. Confirm the job list loads.
3. Change search/type/status/date filters and confirm refresh.
4. Change page size and use previous/next pagination.
5. Open a task detail modal from a task id.
6. Copy task id/request/response data.
7. Open output preview for a succeeded task with outputs.
8. Close modal by close button, backdrop, and Escape.
9. Confirm browser console has no selector, binding, or fetch errors.

## Stop Conditions

Stop the task if:

- Any task-log selector cannot be found before binding.
- A future change requires renaming ids or data attributes.
- A future change requires changing route value `space`.
- A future change requires changing server route shape.
- A future change would stage `styles/task-log.css` unintentionally.
- `npm run check` or `npm run build` fails.
